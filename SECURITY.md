# Security Policy

## Supported version

The current `main` branch is the supported version of this prototype.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability.

If GitHub private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option in the repository Security tab. Otherwise, contact the repository owner through their GitHub profile with:

- A concise description of the issue.
- Steps to reproduce it.
- Potential impact.
- Any suggested mitigation, if available.

Please allow reasonable time for review and remediation before public disclosure.

## Public demo safety

This application is a public demonstration prototype. Do not enter, upload, export, commit, or share:

- Client-confidential information.
- Personally identifiable information.
- Credentials, secrets, tokens, or API keys.
- Proprietary presentation content.
- Sensitive production financial data.

Use representative, sanitized, or fictional assumptions when demonstrating the app.

## Scope

The toolkit currently runs as a Streamlit application and does not require users to provide credentials or connect external accounts. Security reports concerning dependencies, deployed configuration, accidental secrets, or unexpected data exposure are in scope.
